查看所有已加载的驱动
命令	作用	说明
lsmod	列出所有作为内核模块加载的驱动。	这是最直接的方法，但注意，很多基础驱动是静态编译进内核的，不会在这里显示。
cat /proc/devices	列出系统中所有已注册的字符设备和块设备及其主设备号。	它能展示一个更全面的设备驱动列表，无论驱动是静态编译还是动态加载的。
ls /sys/module/	列出所有已加载的内核模块（包括静态和动态的）。	这是一个更全面的查看模块的方法，因为/sys/module/目录下包含了所有当前内核已加载的模块信息。

查看特定驱动（以串口为例）
命令	作用	说明
cat /proc/tty/drivers	列出内核支持的所有tty设备（包括串口）及其驱动信息。	这是查看串口驱动最直接的命令之一。
cat /proc/tty/driver/serial	显示串口（通常是标准UART）的硬件信息及状态。	提供更具体的串口硬件信息。
ls -l /dev/tty*	列出所有串口设备节点文件，如/dev/ttyS0, /dev/ttyUSB0等。	设备节点是驱动与硬件通信的接口，通过它可以知道系统识别了哪些串口硬件。
dmesg | grep -i tty	查看内核日志，筛选出与串口（tty）相关的启动和运行时信息。	对于排查驱动加载失败或硬件识别问题非常有用。

相机相关：
核心查看命令
命令	作用	说明
dumpsys media.camera	获取相机系统服务的详细信息	这是最重要的命令，可以查看系统识别到的摄像头数量、ID、HAL层状态等。不同设备服务名可能略有不同，可以试试 dumpsys cameraservice 或 dumpsys | grep -i camera 来确认。
ls -l /dev/video*	列出所有视频设备节点	相机通常对应 /dev/video 节点。执行后可看到系统为相机设备创建的节点文件，这是驱动与硬件通信的接口。
lsmod | grep -i camera	查看是否加载了相机相关的内核模块	此命令可检查驱动模块是否被加载。如果相机驱动是以模块（.ko文件）形式存在的，加载后这里会有显示。
cat /proc/driver/camera_info	查看摄像头信息（部分平台适用）	这是一个直接查看摄像头信息的接口，但并非所有平台都支持。在不支持的设备上会提示文件不存在。
cat /sys/kernel/debug/usb/devices	列出所有USB设备的详细信息	针对USB摄像头，此命令可查看其VID（Vendor ID）和PID（Product ID）。
