**查看内存使用情况**
```
dumpsys meminfo
dumpsys meminfo <应用包名>

free -m

cat /proc/meminfo

top -m 3 显示内存占用最高的3个进程
top -n 1 只显示一次
top -H -p 4738 显示指定进程的线程的内存占用情况，4738是进程ID
ps -T -p 4738
cat /proc/4738/task/*/stat | awk '{print $1, $14, $15}' 
```
