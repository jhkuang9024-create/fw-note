## 熄屏时暂停播放视频

参考实现：拉起首页触发播放应用的onStop来暂停，过度版椰壳实现：拉起桌面com.komect.ajlauncher/com.komect.bussness.epg.EpgHomeActivity       实现：launchHomeFromHotKey(DEFAULT_DISPLAY);

在拉起时要处理isUserSetupComplete方法的判断逻辑，增加只要顶层activity不是com.cmcc.jarvis.bind.BindDevice2Activity就设置isSetupComplete为true

```
import android.app.ActivityManager.RunningTaskInfo;
private boolean mUserSetupComplete = false;

if (!isSetupComplete) {
    try {
        if(!mUserSetupComplete){
            List<RunningTaskInfo> tasks = ActivityManager.getService().getTasks(1);
            if (tasks != null && !tasks.isEmpty()) {
                ComponentName topActivity = tasks.get(0).topActivity;
                if (topActivity != null) {
                    String className = topActivity.getClassName();
                    if (!"com.cmcc.jarvis.bind.BindDevice2Activity".equals(className)) {
                        isSetupComplete = true;
                        mUserSetupComplete = true;
                    }
                }
            }
        }else{
            isSetupComplete = mUserSetupComplete;
        }
    } catch (Exception e) {}
}
```
