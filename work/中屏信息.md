
## 语音交互

### 打开应用

灵犀智能体(com.cmcc.lingxiagent)拿到语音文本，应用内部查询到包名：greenDAO: Values for query: [com.czly.tabletmusic]
然后在底座(com.cmcc.jarvis)处理启动请求：jarvis_ProcessLifeImps: activityStarting:packageName = com.czly.tabletmusic,pageName = com.czly.tabletmusic.activities.SplashActivity 
然后在system_server进程启动：ActivityTaskManager: START u0
